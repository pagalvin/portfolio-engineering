# AI providers

Portfolio OS supports a growing list of AI providers through its bring-your-own-key (BYOA) model. Each provider defines its own required fields — for example, an API key and model name, or an endpoint, deployment name, and API version — so the setup form only asks for what your chosen provider actually needs.

This page lists providers currently available to connect, and providers planned for future support. A provider appearing here does not mean Portfolio OS has an account with it; you always supply your own credentials.

If a provider you want to use is not yet listed, it is not currently supported for connection setup, even if Portfolio OS may reference it elsewhere.
